# PixVerse Java SDK for RunAPI

Add `ai.runapi:runapi-pixverse` and use `PixVerseClient` for all five PixVerse V6 video resources.

Gradle:

```kotlin
dependencies {
  implementation("ai.runapi:runapi-pixverse:0.1.1")
}
```

Maven:

```xml
<dependency>
  <groupId>ai.runapi</groupId>
  <artifactId>runapi-pixverse</artifactId>
  <version>0.1.1</version>
</dependency>
```

Model details and pricing: https://runapi.ai/models/pixverse/pixverse-v6
